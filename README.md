# One Letter: Coffee or Tea

One letter, A for coffee or B for tea.

This entry picks **A — coffee**: the vivid, punchy, honest answer.

## Run it

```sh
python3 main.py
```

It writes exactly one character (`A`, no newline) to `/output/entry.txt`.
